================================================================================
Exercise 03: Replace Send/Recv with Gather
================================================================================

Description:
In Exercise 2, partial sums were collected on root using an O(P) sequential
loop with MPI_Send and MPI_Recv.

In Exercise 3, MPI_Gather replaces the entire point-to-point communication loop:
1. Memory Allocation:
   - Root allocates the full array (N ints) and an array all_sums of size 'size'
     (long long) to receive the partial sum from each rank.
   - All processes allocate only a local chunk buffer of size chunk_size = N / size.
2. MPI_Gather:
   - Each process sends its local_sum (1 long long value).
   - Root gathers these values in rank order into all_sums[].
3. Summation:
   - Gather does not compute; root loops through all_sums[0..size-1] to calculate
     the total sum.
